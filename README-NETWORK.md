# Доступ к сайту с других компьютеров

## Быстрый старт

1. Запустите контейнер:
```cmd
docker compose down -v
docker compose up -d --build
```

2. Узнайте ваш локальный IP:
```cmd
ipconfig
```
Ищите "IPv4 Address" (например, `192.168.1.100`)

3. На другом компьютере откройте в браузере:
- `http://ваш-локальный-ip` (например, `http://192.168.1.100`)
- или `http://ваш-локальный-ip:3000`

## Автоматическая настройка

Запустите скрипт:
```cmd
setup-network-access.bat
```

Он покажет ваш IP и инструкции.

## Варианты доступа

### 1. Локальная сеть (Wi-Fi/LAN)

**Требования:**
- Компьютеры в одной сети
- Брандмауэр разрешает порты 80 и 3000

**Доступ:**
- `http://ваш-локальный-ip`
- `http://ваш-локальный-ip:3000`

### 2. Интернет (публичный доступ)

#### Вариант A: Проброс портов через роутер

1. Зайдите в настройки роутера (обычно `192.168.1.1`)
2. Найдите "Port Forwarding" или "Виртуальные серверы"
3. Настройте проброс:
   - Внешний порт: 80
   - Внутренний порт: 80
   - Внутренний IP: ваш локальный IP
   - Протокол: TCP
4. Узнайте ваш внешний IP: https://whatismyipaddress.com
5. Сайт будет доступен: `http://ваш-внешний-ip`

**⚠️ Внимание:** Открытие портов может быть небезопасно. Используйте HTTPS и настройте безопасность.

#### Вариант B: Ngrok (проще и безопаснее)

1. Скачайте ngrok: https://ngrok.com/download
2. Запустите:
```cmd
ngrok http 80
```
3. Вы получите публичный URL вида: `https://xxxx-xxxx-xxxx.ngrok.io`

#### Вариант C: Cloudflare Tunnel (возврат)

Если хотите вернуть Cloudflare tunnel, добавьте обратно в `docker-compose.yml`.

## Настройка брандмауэра Windows

Если другие компьютеры не могут подключиться:

1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Создайте правило для входящих подключений:
   - Тип: Порт
   - Протокол: TCP
   - Порт: 80 и 3000
   - Действие: Разрешить подключение

Или через командную строку (от администратора):
```cmd
netsh advfirewall firewall add rule name="Docker Web Server" dir=in action=allow protocol=TCP localport=80,3000
```

## Проверка доступности

### С вашего компьютера:
```cmd
curl http://localhost
```

### С другого компьютера в сети:
```cmd
curl http://ваш-локальный-ip
```

### Проверка портов:
```cmd
netstat -ano | findstr ":80 "
netstat -ano | findstr ":3000 "
```

## Решение проблем

### Проблема: Не могу подключиться с другого ПК

**Решения:**
1. Проверьте, что контейнер запущен: `docker compose ps`
2. Проверьте брандмауэр Windows
3. Убедитесь, что компьютеры в одной сети
4. Проверьте IP адрес: `ipconfig`
5. Попробуйте другой порт (3000 вместо 80)

### Проблема: Порт 80 занят

**Решение:**
Используйте порт 3000: `http://ваш-ip:3000`

### Проблема: Брандмауэр блокирует

**Решение:**
Разрешите порты 80 и 3000 в настройках брандмауэра (см. выше)

## Безопасность

⚠️ **Важно:**
- Локальный доступ в сети - относительно безопасен
- Публичный доступ через интернет - требует настройки безопасности
- Рекомендуется использовать HTTPS
- Настройте аутентификацию для публичного доступа
- Регулярно обновляйте систему и Docker
