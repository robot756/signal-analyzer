# Локальный доступ к сайту

## Быстрый старт

1. Запустите контейнер:
```cmd
docker compose down -v
docker compose up -d --build
```

2. Откройте в браузере:
- **Основной адрес:** http://localhost
- **Альтернативный:** http://localhost:3000

## Доступ к сайту

Сайт доступен локально по адресам:
- `http://localhost` (порт 80)
- `http://localhost:3000` (если порт 80 занят)

## Проверка статуса

```cmd
docker compose ps
```

## Просмотр логов

```cmd
docker compose logs -f react
```

## Остановка

```cmd
docker compose down
```

## Публичный доступ (опционально)

Если нужен публичный доступ из интернета, используйте один из вариантов:

### Вариант 1: Проброс портов через роутер
1. Настройте проброс порта 80 на ваш компьютер в настройках роутера
2. Узнайте ваш внешний IP: https://whatismyipaddress.com
3. Сайт будет доступен по адресу: `http://ваш-внешний-ip`

### Вариант 2: Использовать ngrok
```cmd
ngrok http 80
```

### Вариант 3: Использовать локальную сеть
Если вы в локальной сети, другие устройства могут получить доступ по:
- `http://ваш-локальный-ip` (например, `http://192.168.1.100`)

Узнать локальный IP:
```cmd
ipconfig
```
Ищите "IPv4 Address" в разделе вашего сетевого адаптера.

## Решение проблем

### Порт 80 занят

Если порт 80 занят другим приложением:

1. Остановите другое приложение, использующее порт 80
2. Или используйте альтернативный порт 3000: `http://localhost:3000`

### Проверка, какой процесс использует порт 80

```cmd
netstat -ano | findstr :80
```

### Проверка работы сайта

```cmd
curl http://localhost
```

Или откройте в браузере: `http://localhost`
