# Решение проблем с Docker

## Сайт не работает - пошаговая диагностика

### Шаг 1: Проверьте статус контейнеров

```cmd
docker compose ps
```

Оба контейнера должны быть в статусе "Up". Если нет - смотрите логи.

### Шаг 2: Проверьте логи React приложения

```cmd
docker compose logs react
```

**Возможные проблемы:**
- Если видите ошибки сборки - проверьте `package.json` и зависимости
- Если видите "nginx: [emerg]" - проблема в конфигурации nginx
- Если видите "index.html not found" - проблема со сборкой React

### Шаг 3: Проверьте логи Tunnel

```cmd
docker compose logs tunnel
```

**Возможные проблемы:**
- Если tunnel не может подключиться к react - проверьте сеть
- Если видите ошибки подключения - react контейнер может быть не готов

### Шаг 4: Проверьте локальный доступ

Откройте в браузере: `http://localhost`

Если локально работает, но через tunnel нет - проблема в tunnel.
Если локально не работает - проблема в react/nginx.

### Шаг 5: Используйте диагностический скрипт

```cmd
check-status.bat
```

Этот скрипт автоматически проверит все вышеперечисленное.

## Частые проблемы и решения

### Проблема 1: Контейнеры не запускаются

**Решение:**
```cmd
docker compose down -v
docker compose up -d --build
```

### Проблема 2: Ошибка сборки React

**Решение:**
1. Проверьте, что все зависимости установлены:
```cmd
npm install
```

2. Попробуйте собрать локально:
```cmd
npm run build
```

3. Если локально работает, но в Docker нет - проверьте `.dockerignore`

### Проблема 3: Nginx не запускается

**Решение:**
1. Проверьте конфигурацию nginx:
```cmd
docker compose exec react nginx -t
```

2. Если ошибка - проверьте `nginx.conf` на синтаксические ошибки

### Проблема 4: Tunnel не может подключиться

**Решение:**
1. Убедитесь, что react контейнер здоров:
```cmd
docker compose ps
```

2. Проверьте, что они в одной сети:
```cmd
docker network inspect signal-analyzer_app-network
```

3. Попробуйте перезапустить tunnel:
```cmd
docker compose restart tunnel
```

### Проблема 5: Сайт открывается, но показывает ошибку

**Решение:**
1. Откройте консоль браузера (F12) и проверьте ошибки
2. Проверьте, что все файлы загружаются:
   - Откройте Network вкладку в DevTools
   - Проверьте статус загрузки файлов

## Полная переустановка

Если ничего не помогает:

```cmd
docker compose down -v
docker system prune -a
docker compose up -d --build
```

**Внимание:** Это удалит все неиспользуемые образы и контейнеры!

## Получение помощи

Если проблема не решена, соберите следующую информацию:

```cmd
docker compose ps > status.txt
docker compose logs react > react-logs.txt
docker compose logs tunnel > tunnel-logs.txt
docker compose config > config.txt
```

Отправьте эти файлы для диагностики.
